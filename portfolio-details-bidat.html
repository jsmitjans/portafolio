Descripción del proyecto

En este proyecto desarrollé el módulo de Visualizaciones para el Banco Integrado de Datos (BIDAT) del Ministerio de Desarrollo Social y Familia. El objetivo principal fue centralizar en una única plataforma diversos reportes que anteriormente se encontraban dispersos en archivos Excel o en sistemas separados, facilitando así el acceso y análisis de información relevante para el ministerio.

Reportes implementados:

  • Encuesta CASEN: Visualización de los resultados de la Encuesta de Caracterización Socioeconómica Nacional.
  • Registro Social de Hogares: Reportes con datos del registro que caracteriza la situación socioeconómica de los hogares chilenos.
  • Banco Integrado de Inversión Pública: Información consolidada sobre proyectos de inversión pública.

Funcionalidades desarrolladas:

  • Mantenedores: Interfaces para la administración y configuración de los datos base del sistema.
  • Gráficos interactivos: Visualizaciones dinámicas que permiten analizar los datos de manera intuitiva.
  • Carga masiva de datos: Funcionalidad para importar grandes volúmenes de información de manera eficiente.
